# Hi, I'm Bob

I build evaluation datasets, human annotation protocols, and reliable agentic systems for LLM research.

My current focus is on:

- LLM evaluation and benchmark design
- post-training data and feedback workflows
- human evaluation and annotation protocols
- agent reliability, auditability, and evaluator checks
- dataset construction from messy real-world text

## Flagship Projects

### Cybersecurity Readability Annotation

Span-level human-evaluation template for identifying cybersecurity jargon, legal terminology, platform references, community slang, and implicit background knowledge in Reddit discussion text.

Research signal: dataset construction, annotation guideline design, label taxonomy, validation, provenance, and release-risk awareness.

### NeoBench Evaluation Work

Evaluation work for studying model behavior on benchmark-style tasks, with emphasis on task design, metrics, failure analysis, and reproducible evaluation artifacts.

Research signal: LLM evaluation, benchmark analysis, human/model comparison, and post-training relevance.

### Agentic NLP Research Assistant

Deterministic research-assistant scaffold with typed state, local retrieval, claim extraction, evaluator checks, JSON-backed memory, and auditable research artifacts.

Research signal: agent reliability, orchestration, retrieval-grounded synthesis, and evaluator-backed blocking conditions.
